# Security Policy

## Public security posture

This repository intentionally contains architecture documentation and sanitized examples only.

Do not publish:

- credentials;
- API keys;
- private endpoints;
- exploitable production configuration;
- customer data;
- security-sensitive policy internals;
- proprietary deployment automation.

## Reporting a security issue

Please report suspected security issues privately to myGO through an official private contact channel rather than opening a public GitHub issue containing exploit details.

When reporting, include:

- affected component or document;
- impact;
- reproduction steps where safe;
- relevant environment/version;
- suggested mitigation if known.

## Scope note

Because this repository is primarily a public protocol/documentation repository, implementation-specific vulnerability handling may occur in the corresponding private deployment channel.
