# Glossary

**Decision Intelligence** - AI-assisted problem framing, analysis, alternatives, evidence requirements and planning.

**Deterministic Control Plane** - Software authority layer that owns state, policy, permissions, approvals and transitions.

**Execution Runtime** - Bounded executor of authorized actions.

**Critic / Verifier** - Independent verification layer for claims, tests, artifacts and acceptance criteria.

**Outcome Layer** - Records real-world results after execution and verification.

**AuthorizationGrant** - Scoped permission for a specific actor/action/environment/resource.

**Evidence Provenance** - Traceability of where evidence came from, how it was obtained and what it supports.

**Domain Profile** - Domain-specific methods, risks, evidence requirements, tools and critic rules.

**Model Gateway** - Provider-neutral model routing and capability abstraction.

**Governed Improvement** - Controlled candidate-change pipeline with evaluation and promotion gates.

**Durable Execution** - Workflow execution that can survive failures, delays and retries without losing authoritative state.

**Prompt Wrapper** - A simple application that mainly passes input to an LLM and returns output without a deeper state/authority architecture.
