# Public Roadmap

This roadmap describes architectural maturation rather than promising public release dates.

## Phase 1 - Protocol Baseline

- public architecture;
- role boundaries;
- governance invariants;
- contract catalog;
- public/private boundary.

## Phase 2 - Verification & Evidence

- critic protocol;
- evidence/claim model;
- verdict semantics;
- acceptance-evidence mapping.

## Phase 3 - Policy & Capability Security

- capability manifests;
- scoped authorization;
- approval freshness;
- environment/resource/tool scoping.

## Phase 4 - Durable Orchestration

- checkpoints;
- retries;
- idempotency;
- pause/resume/cancel;
- recovery and reconciliation.

## Phase 5 - Outcome & Evaluation

- outcome contract;
- real-world feedback;
- evaluation classes;
- regression/adversarial evaluation.

## Phase 6 - Governed Improvement

- candidate lessons;
- improvement candidates;
- promotion gates;
- canary/staging;
- rollback and provenance.

## Production milestone

A production-ready implementation should not be declared complete until the control plane, verification path, failure recovery, security model and auditability are demonstrably enforceable.
